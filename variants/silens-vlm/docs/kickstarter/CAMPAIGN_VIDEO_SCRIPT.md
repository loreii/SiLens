## PRODUCTION NOTES

### Tone Guidelines
- Confident but not arrogant
- Technical but accessible
- Enthusiastic but grounded
- Problem-focused, then solution-focused

### Pacing
- Hook: FAST (grab attention)
- Problem: MODERATE (build understanding)
- Solution: MODERATE (explain clearly)
- Demo: FAST (show don't tell)
- Use Cases: FAST (montage style)
- Ask: SLOWER (clear call to action)

### Key Messages to Emphasize
1. 100× faster than GPU
2. Half the price
3. 25 watts (vs 115W)
4. Open source
5. Privacy (local processing)

### Things to Avoid
- Over-promising on timeline
- Claiming it replaces all GPUs (it's purpose-built)
- Technical jargon without explanation
- Mentioning competitors by name negatively
