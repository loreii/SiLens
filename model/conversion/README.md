# Model Conversion Tools

## Overview

This directory contains tools to convert SmolVLM-256M from PyTorch format to:
1. Quantized weights (1-bit/ternary)
2. Verilog weight modules
3. Memory initialization files

## Pipeline

```
PyTorch Model (FP16/FP32)
        ↓
   Quantization (1-bit)
        ↓
   Weight Export (binary files)
        ↓
   Verilog Generation (hardwired modules)
```

## Scripts

### `download_model.py`
Download SmolVLM-256M from Hugging Face.

```bash
python download_model.py --output model/smolvlm-256m
```

### `analyze_model.py`
Analyze model architecture and weight distributions.

```bash
python analyze_model.py --model model/smolvlm-256m
```

Output:
- Layer shapes and sizes
- Weight statistics
- Quantization-friendly analysis

### `quantize.py`
Quantize weights to 1-bit (ternary: -1, 0, +1).

```bash
python quantize.py \
    --model model/smolvlm-256m \
    --output model/weights/quantized \
    --method ste  # Straight-through estimator
```

Options:
- `--method`: Quantization method (ste, gptq, awq)
- `--calibration-data`: Dataset for calibration
- `--bits`: Target bits (1 for ternary)

### `convert_to_verilog.py`
Generate Verilog modules from quantized weights.

```bash
python convert_to_verilog.py \
    --weights model/weights/quantized \
    --output rtl/*/weights/
```

Generates:
- Weight modules for each layer
- Parameter files
- Include files

### `validate.py`
Validate quantized model accuracy.

```bash
python validate.py \
    --original model/smolvlm-256m \
    --quantized model/weights/quantized \
    --dataset textvqa
```

## Quantization Methods

### Ternary Quantization

For weight w:
```
q(w) = +1  if w > threshold
     = -1  if w < -threshold
     =  0  otherwise

threshold = α * mean(|w|)  # α typically 0.7-0.8
```

### Hardware Encoding

```python
def encode_weight(w):
    """Encode weight for hardware."""
    if w > 0:
        return 0b01  # +1: connect to VDD
    elif w < 0:
        return 0b10  # -1: connect to GND
    else:
        return 0b00  # 0: no connection
```

## Expected Quality

| Metric | FP16 | 1-bit | Degradation |
|--------|------|-------|-------------|
| VQAv2 | 71% | 65-68% | 3-6% |
| TextVQA | 55% | 48-52% | 3-7% |
| COCO Caption | 0.85 | 0.78-0.82 | 3-8% |

Quality loss is acceptable for many applications, especially:
- Draft generation (speculative decoding)
- Real-time processing (where speed matters)
- Edge deployment (where alternatives are worse)

## Verilog Output Format

Generated weight modules:

```verilog
// Auto-generated by convert_to_verilog.py
// Layer: vision_encoder.blocks.0.attn.qkv
// Shape: [768, 2304]
// Sparsity: 12.3%

module vision_encoder_block0_attn_qkv_weights (
    input  wire [767:0] input_vec,
    output wire [2303:0] output_vec
);
    // Row 0: weights = [+1, -1, 0, +1, ...]
    assign output_vec[0] = input_vec[0];       // +1
    assign output_vec[1] = ~input_vec[1] + 1;  // -1
    assign output_vec[2] = 8'b0;               // 0
    // ... (continues for all weights)
endmodule
```
