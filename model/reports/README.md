# SiLens Model Reports

This directory contains sample reports generated by the SiLens model conversion and validation tools.

## Report Types

### 1. Quantization Reports
Generated by `quantize_ternary.py` and `validate_quantization.py`.

**Contents:**
- Weight distribution statistics
- Per-layer quality metrics
- Compression ratios
- Problematic layer identification
- Recommendations

**Example:** `sample_quantization_report.json`

### 2. Benchmark Reports
Generated by `benchmark_suite.py` and related validation tools.

**Contents:**
- VQA/TextVQA accuracy
- Perplexity measurements
- Inference comparison
- Hardware estimates

**Example:** `sample_benchmark_report.json`

## Generating Reports

### Full Pipeline Report
```bash
python run_pipeline.py --model HuggingFaceTB/SmolVLM-256M-Instruct \
    --output ./model/reports/my_report
```

### Individual Reports
```bash
# Quantization report
python validate_quantization.py --model HuggingFaceTB/SmolVLM-256M-Instruct \
    --output ./model/reports/quantization.json

# Benchmark report  
python validation/benchmark_suite.py --model HuggingFaceTB/SmolVLM-256M-Instruct \
    --all --output ./model/reports/benchmark.json

# Sensitivity analysis
python sensitivity_analysis.py --model HuggingFaceTB/SmolVLM-256M-Instruct \
    --output ./model/reports/sensitivity.json
```

## Understanding Reports

### Key Metrics to Monitor

| Metric | Good | Acceptable | Needs Attention |
|--------|------|------------|-----------------|
| Cosine Similarity | > 0.95 | 0.90-0.95 | < 0.90 |
| VQA Accuracy Drop | < 3% | 3-7% | > 7% |
| Perplexity Increase | < 10% | 10-20% | > 20% |
| Sparsity | 30-40% | 25-50% | < 25% or > 50% |

### Acting on Recommendations

Reports include prioritized recommendations. Common actions:

1. **High Priority:** Usually involves changing quantization parameters
2. **Medium Priority:** Optimization opportunities
3. **Low Priority:** Minor improvements for edge cases

## Archiving Reports

Best practice: Keep reports with your quantized models for reproducibility.

```
model/weights/quantized/
├── weights/
├── quantization_metadata.json
└── reports/
    ├── quantization_report.json
    ├── benchmark_report.json
    └── sensitivity_analysis.json
```
